House Price Prediction using Linear Regression

Overview:
This project predicts housing prices based on features like average income, number of rooms, population, and location.
It applies Linear Regression — one of the fundamental supervised learning algorithms in Machine Learning.

Objective:
To understand how linear regression models learn relationships between variables and make numerical predictions.

Dataset
Source: California Housing Prices Dataset (Kaggle)

Features:
longitude, latitude, housing_median_age, total_rooms, total_bedrooms, population, households, median_income, ocean_proximity
Target: median_house_value

Tools & Libraries:
Python,
Pandas,
NumPy,
Matplotlib,
Seaborn,
Scikit-learn

Steps Involved
Data loading and cleaning,
Feature selection and preprocessing,
Model training using Linear Regression,
Evaluation using RMSE and R² score,
Visualization of predicted vs actual values

Results
RMSE: 69,297.72,
R² Score: 0.64,
Model performed well for predicting median housing prices.
